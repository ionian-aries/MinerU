# MinerU Hybrid-Auto-Engine 工作流程详解

> **文档定位**: 详细解析 Hybrid-Auto-Engine 模式的完整工作流程，包括模型分析阶段和输出处理阶段。

---

## 总览

Hybrid-Auto-Engine 模式采用 **VLM (Vision Language Model) 端到端推理 + 传统模型补充** 的混合架构，相比传统 Pipeline 模式大幅简化了模型数量和流程复杂度。

```mermaid
flowchart LR
    subgraph STAGE1["阶段一：模型分析 (aio_hybrid_doc_analyze)"]
        direction TB
        S1["VLM版面分析+内容提取<br/>aio_batch_two_step_extract"]
        S1 --> S2{"VLM OCR启用?"}
        S2 -->|否| S3["_process_ocr_and_formulas<br/>补充行内公式+OCR"]
        S2 -->|是| S4["跳过本地OCR"]
        S3 --> S5["逐页转换 middle_json"]
        S4 --> S5
        S5 --> S6["finalize_middle_json<br/>文档级后处理"]
    end

    subgraph STAGE2["阶段二：输出处理 (_process_output)"]
        direction TB
        P1["选择生成函数<br/>vlm_union_make"]
        P1 --> P2["可视化输出<br/>draw_layout_bbox等"]
        P2 --> P3["内容生成<br/>Markdown/JSON"]
        P3 --> P4["文件写入<br/>md_writer.write_string"]
    end

    PDF([PDF输入]) --> STAGE1 --> STAGE2 --> OUT([.md / .json / images/])

    style STAGE1 fill:#e3f2fd,stroke:#1565c0
    style STAGE2 fill:#fff3e0,stroke:#e65100
```

## 阶段一：模型分析阶段 (aio_hybrid_doc_analyze)

**入口**: `aio_hybrid_doc_analyze()`  
**源文件**: `mineru/backend/hybrid/hybrid_analyze.py`

### 1.1 初始化阶段

```mermaid
flowchart TD
    I1["ModelSingleton().get_model()<br/>获取VLM预测器实例"] --> I2
    I2["ocr_classify()<br/>根据parse_method判断OCR模式"] --> I3
    I3["_should_enable_vlm_ocr()<br/>判断是否启用VLM端到端OCR<br/>条件: ocr_enable && language∈[ch,en] && inline_formula_enable"] --> I4
    I4["init_middle_json()<br/>初始化middle_json结构<br/>含_ocr_enable/_vlm_ocr_enable标记"] --> I5
    I5["open_pdfium_document()<br/>打开PDF文档"]
```

### 1.2 分窗口处理循环

| 步骤 | 函数 | 作用 |
|------|------|------|
| 1 | `get_processing_window_size()` | 获取处理窗口大小（默认64页） |
| 2 | `get_batch_ratio()` | 根据显存大小计算batch_ratio（1-16） |
| 3 | `load_images_from_pdf_doc()` | 将PDF页面渲染为PIL Image列表 |

### 1.3 VLM推理核心 (aio_batch_two_step_extract)

```mermaid
flowchart TD
    V1["输入: PIL Image列表"] --> V2{"batching_mode?"}
    V2 -->|stepping| V3["aio_stepping_two_step_extract"]
    V2 -->|concurrent| V4["aio_concurrent_two_step_extract"]
    
    subgraph STEPPING["stepping模式详细流程"]
        S1["aio_batch_layout_detect()<br/>第1步: 版面检测<br/>返回每页block列表(含bbox/type)"] --> S2
        S2["aio_prepare_for_extract()<br/>第2步: 准备提取输入<br/>裁剪block图片+构造prompt"] --> S3
        S3["aio_batch_predict()<br/>第3步: VLM内容提取<br/>识别每个block的具体内容"] --> S4
        S4["aio_post_process()<br/>第4步: 后处理<br/>格式化输出结果"]
    end
    
    V3 --> STEPPING
```

**返回值结构**:
```python
window_model_list: list[ExtractResult]
# 每页一个ExtractResult，内部是block列表
[
    [
        {"type": "text", "bbox": [x0,y0,x1,y1], "content": "正文"},
        {"type": "table", "bbox": [...], "content": "<table>...</table>"},
        {"type": "equation", "bbox": [...], "content": "latex"},
        {"type": "image", "bbox": [...], "content": ""},
    ],
    [...]  # 第1页
]
```

### 1.4 OCR与公式补充 (_process_ocr_and_formulas)

当 `_vlm_ocr_enable=False` 时执行，补充VLM未覆盖的行内公式和OCR文本：

```mermaid
flowchart TD
    subgraph INPUT["输入参数"]
        IN1[images_pil_list: PIL Image列表]
        IN2[model_list: VLM版面分析结果]
        IN3[language: 语言]
        IN4[inline_formula_enable: 行内公式开关]
        IN5[_ocr_enable: OCR开关]
        IN6[batch_ratio: 批处理比例]
    end

    subgraph INIT["初始化"]
        N1["PIL转numpy数组"] --> N2
        N2["HybridModelSingleton().get_model()<br/>获取混合模型实例<br/>包含layout/mfr/ocr模型"]
    end

    subgraph INLINE["行内公式处理<br/>inline_formula_enable=True"]
        M1["mask_image_regions()<br/>遮罩图片/表格/行间公式"] --> M2
        M2["layout_model.batch_predict()<br/>检测行内公式位置"] --> M3
        M3["_build_inline_formula_inputs()<br/>构建行内公式输入"] --> M4
        M4["mfr_model.batch_predict()<br/>公式识别→LaTeX"]
    end

    subgraph OCR_DET["OCR检测阶段"]
        O1{"enable_ocr_det_batch?"} -->|False| O2["非批处理模式<br/>逐页逐block处理"]
        O1 -->|True| O3["批处理模式<br/>按64px分辨率分组"]
    end

    subgraph OCR_REC["OCR识别阶段<br/>_ocr_enable=True"]
        R1["收集含np_img的span"] --> R2
        R2["ocr_model.ocr(det=False)<br/>批量文字识别"] --> R3
        R3["质量过滤<br/>置信度<min删除<br/>噪声文本删除"]
    end

    subgraph MERGE["合并与归一化"]
        U1["_normalize_bbox()<br/>坐标归一化[0,1]"] --> U2
        U2["_merge_page_sidecar_items()<br/>合并VLM+公式+OCR结果"]
    end

    INPUT --> INIT --> INLINE --> OCR_DET --> OCR_REC --> MERGE
```

**详细步骤**:

| 行号 | 函数 | 作用 |
|------|------|------|
| L255 | `np_images = [np.asarray(pil_image).copy()...]` | PIL转numpy数组 |
| L258-262 | `hybrid_model_singleton.get_model()` | 获取混合模型实例 |
| L270 | `mask_image_regions(np_images, model_list)` | 涂白干扰区域 |
| L273-276 | `layout_model.batch_predict()` | 检测行内公式位置 |
| L280-284 | `mfr_model.batch_predict()` | 公式识别→LaTeX |
| L298 | `ocr_det()` | OCR文字检测 |
| L313 | `ocr_model.ocr(img_crop_list, det=False)` | OCR文字识别 |
| L400 | `_normalize_bbox()` | 坐标归一化 |
| L401-406 | `_merge_page_sidecar_items()` | 合并三类结果 |

**返回值**:
```python
return merged_model_list, hybrid_pipeline_model

# merged_model_list: 合并后的每页block列表
[
    [
        # VLM原始结果
        {"type": "text", "bbox": [...], "content": "正文"},
        {"type": "table", "bbox": [...], "content": "<table>"},
        # 行内公式（新增）
        {"type": "inline_formula", "bbox": [...], "latex": "\\sum x_i", "score": 0.95},
        # OCR文本（新增）
        {"type": "ocr_text", "bbox": [...], "text": "OCR文字", "score": 0.92},
    ],
    [...]
]

# hybrid_pipeline_model: 混合模型实例
```

### 1.5 逐页转换 middle_json

```mermaid
flowchart TD
    A1["append_page_model_list_to_middle_json()"] --> A2
    A2["blocks_to_page_info()<br/>构造页面信息"] --> A3
    A3["MagicModel()<br/>构建block/line/span结构"] --> A4
    A4["cut_image_and_table()<br/>截图保存到images/"]
```

**MagicModel 构造** (`hybrid_magic_model.py`):

| 步骤 | 方法 | 功能 |
|------|------|------|
| 1 | `_split_page_model_list()` | 拆分VLM结果、行内公式、OCR结果 |
| 2 | `cal_real_bbox()` | bbox坐标转换 |
| 3 | 构建`page_blocks` | 按类型分类block |
| 4 | `get_image_blocks()` / `get_table_blocks()` / `get_text_blocks()` | 分类提取 |
| 5 | `get_all_spans()` | 获取所有span用于截图 |

### 1.6 文档级后处理 (finalize_middle_json)

| 步骤 | 函数 | 功能 |
|------|------|------|
| 1 | `_apply_post_ocr()` | 补充OCR识别（如果未启用VLM OCR） |
| 2 | `cross_page_table_merge()` | 检测并合并跨页表格 |
| 3 | `llm_aided_title()` | LLM辅助优化标题层级（可选） |

## 核心模型清单

| 模型 | 用途 | 触发条件 |
|------|------|----------|
| **VLM (Vision Language Model)** | 端到端版面分析+内容提取 | 始终 |
| **layout模型** | 行内公式位置检测 | `inline_formula_enable=True` |
| **MFR模型** | 行内公式识别→LaTeX | `inline_formula_enable=True` |
| **OCR检测模型** | 文字检测 | `_vlm_ocr_enable=False` |
| **OCR识别模型** | 文字识别 | `_ocr_enable=True` |
