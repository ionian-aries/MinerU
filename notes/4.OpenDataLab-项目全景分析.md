# OpenDataLab 公开项目全景分析

> 来源：GitHub 组织 https://github.com/opendatalab
> 整理日期：2026-04-09

OpenDataLab 是上海人工智能实验室旗下组织，共 **61 个公开仓库**，核心方向为：文档 AI、数据标注、LLM 训练数据、多模态评测和遥感。

---

## 一、文档解析与 PDF 处理（核心方向）

| 仓库 | 功能 | 用途 |
|------|------|------|
| **MinerU** | 端到端文档转换引擎，将 PDF/Word/图片/网页转为 Markdown/JSON | LLM/RAG 数据预处理、文档问答系统 |
| **PDF-Extract-Kit** | 模块化 PDF 内容提取工具包（布局检测、OCR、公式、表格） | 文档翻译、问答助手，是 MinerU 的底层组件库 |
| **DocLayout-YOLO** | 基于 YOLOv10 的实时文档版面检测模型 | 识别 PDF 中的文字块/表格/图片/公式区域 |
| **MinerU-Diffusion** | 基于扩散模型的 OCR 框架，并行解码替代自回归 | 高吞吐量企业文档数字化，比自回归快 3.26x |
| **magic-doc** | PPT/PPTX/DOC/DOCX/PDF → Markdown 轻量转换器 | 旧文档数字化，速度极快（347-1482页/秒） |
| **magic-html** | 从 HTML 提取正文内容（文章/论坛/微信） | 网页内容清洗、LLM 训练数据采集 |
| **MinerU-HTML** | SLM 驱动的 HTML 正文提取器 | AI 工作流中高精度网页内容提取 |
| **MinerU-Webkit** | HTML 网页结构化内容解析与转换（支持 MCP/REST API） | AI Agent 集成，HTML→Markdown/JSON |
| **TRivia** | 表格识别框架（自监督微调，输出 OTSL/HTML） | PDF 表格结构提取 |

### 各仓库详细说明

**MinerU**
- 109 语言 OCR、公式→LaTeX、表格→HTML、多栏布局、扫描 PDF 支持，自动去除页眉页脚页码
- 与 LangChain、Dify、FastGPT 集成
- GitHub: https://github.com/opendatalab/MinerU

**PDF-Extract-Kit**
- 可配置模型组合，针对学术论文/教材/报告等多种文档类型微调
- 包含评测基准，是 MinerU 的底层组件
- GitHub: https://github.com/opendatalab/PDF-Extract-Kit

**DocLayout-YOLO**
- Global-to-Local 可控模块，在 DocSynth300K（30万合成文档）上预训练，DocStructBench 上微调
- GitHub: https://github.com/opendatalab/DocLayout-YOLO

**MinerU-Diffusion**
- 2.5B 参数，单 GPU 可部署，支持布局检测、纯文本 OCR、公式识别（LaTeX）、表格提取（OTSL）
- GitHub: https://github.com/opendatalab/MinerU-Diffusion

**magic-doc**
- 支持本地和 S3 存储文件，处理速度 347–1,482 页/秒
- GitHub: https://github.com/opendatalab/magic-doc

**magic-html**
- 布局专用提取器（文章/论坛），LaTeX 公式提取，WebMainBench F1=0.929，优于 trafilatura/readability-lxml/newspaper3k
- GitHub: https://github.com/opendatalab/magic-html

**MinerU-Webkit**
- 支持 MCP/REST API，可供 AI Agent 调用，高性能异步批处理，lxml 解析
- GitHub: https://github.com/opendatalab/MinerU-Webkit

**TRivia**
- 基于 Qwen2.5-VL-3B 微调（TRivia-3B），处理数字版/扫描/拍照表格，自监督减少标注成本
- GitHub: https://github.com/opendatalab/TRivia

## 三、数学公式识别

**UniMERNet**

## 关键问题解答：mineru.net 网页 URL 解析功能对应哪个仓库？

**结论：主要是 `magic-html` + `MinerU-Webkit` 的组合**

在线工具 https://mineru.net/OpenSourceTools/Extractor 支持输入网页 URL 进行解析，其背后的处理链路为：

```
URL 输入
  → Webkit 渲染引擎抓取页面 HTML
  → magic-html 提取正文内容
  → MinerU-Webkit 结构化转换（→ Markdown/JSON）
  → 输出
```

### magic-html 的核心能力
- 专门针对网页正文提取设计，支持文章、论坛、微信公众号三种页面类型
- 支持 LaTeX 公式提取
- WebMainBench 评测 F1=0.929，优于 trafilatura、readability-lxml、newspaper3k
- GitHub: https://github.com/opendatalab/magic-html

### MinerU-Webkit 的核心能力
- HTML 结构化解析与格式转换（Markdown/JSON/纯文本）
- 支持 MCP（Model Context Protocol）和 REST API，可接入 AI Agent
- 高性能异步批处理，基于 lxml
- GitHub: https://github.com/opendatalab/MinerU-Webkit

## OpenDataLab 整体定位总结

| 核心方向 | 代表仓库 |
|---------|---------|
| 文档 AI / PDF 解析 | MinerU, PDF-Extract-Kit, magic-doc, magic-html, DocLayout-YOLO, MinerU-Diffusion |
| 文档解析评测 | OmniDocBench, OHR-Bench, Miner-PDF-Benchmark, WebMainBench |
| 数学识别 & 表格 | UniMERNet, TRivia |
| 数据标注工具 | labelU, LabelLLM |
| LLM 训练语料 | WanJuan 1/2/3, Meta-rater, MLLM-DataEngine, VIGC |
| 合成图像检测 | FakeVLM, LEGION, LOKI |
| 遥感 / 地球观测 | Earth-Agent, VHM, skydiffusion, MLS-BRN |
| LLM 评测基准 | CHARM, UrBench, ProverGen, OHR-Bench |
| LLM 质量 / 幻觉减少 | HA-DPO, GRAIT, CRaFT |
| 数据集基础设施 | dsdl-sdk, opendatalab-python-sdk, Vis3, allz |

OpenDataLab 是上海人工智能实验室在 AI 数据基础设施领域的核心输出组织，最重点投入的方向是 **MinerU 生态**（文档解析→LLM数据预处理），同时在 CVPR、ICCV、NeurIPS、ACL、AAAI、ICLR 等顶级会议持续发表研究成果。
