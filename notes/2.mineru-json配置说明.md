# mineru.json 配置说明

本文记录 `~/mineru.json` 中各配置项的用途，便于后续运维与交接。

## 配置项说明

### `bucket_info`

- **用途**：对象存储（S3 兼容）访问配置。
- **结构**：`bucket_name -> [ak, sk, endpoint]`。
- **备注**：若仅使用本地文件解析，可不依赖该项。

### `latex-delimiter-config`

- **用途**：控制导出 Markdown 时 LaTeX 公式分隔符。
- **字段**：
  - `display`：块级公式分隔符（例如 `$$...$$`）
  - `inline`：行内公式分隔符（例如 `$...$`）

### `llm-aided-config`

- **用途**：配置 LLM 辅助功能（如标题辅助增强）。
- **常见字段**：
  - `api_key`：上游模型服务密钥
  - `base_url`：兼容 OpenAI 协议的接口地址
  - `model`：模型名称
  - `enable_thinking`：是否启用思考模式（取决于模型能力）
  - `enable`：总开关，`false` 表示关闭

### `models-dir`

- **用途**：配置本地模型目录映射。
- **字段**：
  - `pipeline`：pipeline 模型根目录
  - `vlm`：vlm 模型根目录
- **关键点**：
  - 当环境变量 `MINERU_MODEL_SOURCE=local` 时，会从这里读取路径。
  - 若路径缺失或错误，会导致本地模型加载失败。

### `config_version`

- **用途**：配置版本号，用于兼容升级与模板更新判断。

## 与运行参数的关系

- `-b pipeline`：选择解析后端（算法链路选择）。
- `MINERU_MODEL_SOURCE=local`：选择模型来源（本地目录读取）。
- 两者是不同维度：
  - 一个控制“用哪条解析链路”
  - 一个控制“模型从哪里加载”

## 当前配置结论（基于你现有文件）

- `models-dir` 已配置 `pipeline` 与 `vlm` 的本地路径。
- 可在离线环境中配合 `MINERU_MODEL_SOURCE=local` 使用。
- 无可用 GPU 时，建议命令行显式加 `-b pipeline`。
